#### Accepted syntax and behaviour contract

| ID | Decision |
| --- | --- |
| D01 | `IF condition:` introduces its action suite directly. `ELSE:` aligns with its associated `IF`. No textual `THEN` or `IF: condition` alias remains. |
| D02 | `ALL(c1, c2, ...)`, `ANY(c1, c2, ...)`, and `NOT(c)` are condition operators, not eagerly evaluated function calls. Preserve their authored tree and left-to-right short-circuit evaluation. |
| D03 | `WHILE condition LIMIT N:` uses the same condition grammar. N is a required positive decimal integer literal. Check before each body and after the final allowed body; still true then is a failure, not successful truncation. |
| D04 | `ASSERT condition` reuses the condition grammar and retains optional indented `MESSAGE` metadata. It is not an action-suite header. |
| D05 | A trigger is `id(field=value, ...)` inside its part, on one logical line that may span physical lines. Fields remain explicitly named; `trigger.id` remains its address. |
| D06 | Trigger event/process are required. Source/guard/seed are optional. Authored outer field order may vary; canonical order is event, source, guard, process, seed. Duplicates and unknowns are invalid. |
| D07 | Seed is an OAK named-binding list, not a JSON object or tuple. Preserve binding order and exact input coverage. Omit an empty seed and unconditional guard; explicitly authored `seed=()` or `guard=true` is invalid. |
| D08 | Source-backed triggers forward one complete received schema instance, share resolved schema identity with the process input, and declare no seeds. Source-less triggers use the existing literal/constant/state seed contracts. |
| D09 | Guards require at least one state read and permit fixed literals/constants. They cannot read local process bindings or ambient interfaces. Guard validation and conservative overlap analysis do not expand in this change. |
| D10 | Source-less events match exact text in the executor. Source-backed arrivals match the local receive interface, not an additional event-text test. Matching precedes the guard. No first-match selection or internal-arrival triggering is introduced. |
| D11 | `$` reads a value. Bare part-qualified targets identify entries. Existing relative target support and local-only operations remain unchanged; quoted target-like text stays literal. |
| D12 | Structural action indentation is exactly two spaces and rejects tabs. Newlines inside balanced OAK delimiters continue the statement without creating action scopes. Ordinary blank lines do not change branch association. |
| D13 | Strings and structured literals obey existing JSON rules. Recognise punctuation and operator phrases only outside quoted values and at the correct delimiter depth. No interpolation, single-quoted strings, comments, general calls, truthiness, infix aliases, chained comparisons, or bare grouping expressions are added. |
| D14 | Fixed canonical width is 100 Unicode code points including indentation and the complete header or suffix. Flat lists have no trailing comma. Expanded lists use a trailing comma, two-space item indentation, and owner-aligned closing delimiters; format nested lists recursively. |
| D15 | Wrapping never changes JSON encoding, splits an indivisible value, rewrites literal content, normalises event text, or depends on terminal width. Long atomic values may exceed the soft target. |
| D16 | Canonical Node fields, public semantic APIs, JSON-LD meaning, seven-part order, call frames, child scopes, statement and binding order, transactions, and external-effect limitations remain unchanged. |
| D17 | Replace the old live surface in one pass. Preserve completed historical records, legacy reference, negative fixtures, literal payloads, and semantic identifiers that happen to contain old words. |

These fragments demonstrate the accepted form, not standalone valid documents. The conformance fixtures must supply every referenced entry and required schema contract. Trigger specimens S08 and S09 are alternatives, not duplicate IDs in one document.

S01. Simple comparison, equivalent to the user's first example:

```text
IF $state.ready equals true:
  CALL process.publish ()
```

S02. Alternative branch, equivalent to the user's second example:

```text
IF $state.status equals "ready":
  SET state.status = "complete"
ELSE:
  FAIL "The state is not ready."
```

S03. ALL condition, equivalent to the user's third example:

```text
IF ALL($state.ready equals true, $state.approved equals true):
  CALL process.publish ()
ELSE:
  CALL process.review ()
```

S04. Nested NOT, equivalent to the user's fourth example:

```text
IF ALL($state.ready equals true, NOT($state.blocked equals true)):
  CALL process.publish ()
```

S05. ANY and deeper nesting:

```text
IF ANY($state.ready equals true, $state.override equals true):
  CALL process.publish ()

IF ALL(
  $state.ready equals true,
  ANY($state.approved equals true, $state.override equals true),
  NOT($state.blocked equals true),
):
  CALL process.publish ()
```

S06. Nested branch association:

```text
IF $state.ready equals true:
  IF $state.approved equals true:
    CALL process.publish ()
  ELSE:
    CALL process.review ()
ELSE:
  FAIL "The state is not ready."
```

S07. Simple and compound bounded WHILE. TARGET is a visible input binding; grow-once updates relevant local state:

```text
WHILE $state.balance is less than $TARGET LIMIT 10:
  CALL process.grow-once ()

WHILE ALL($state.balance is less than $TARGET, NOT($state.blocked equals true)) LIMIT 10:
  CALL process.grow-once ()
```

S08. Source-backed trigger, equivalent to the user's unguarded declaration; the authored single-line form is accepted even when canonical rendering wraps it:

```text
request-received(event="A complete OAK authoring request is received.", source=interface.authoring-input, process=process.author-document)
```

S09. Source-backed trigger with guard, equivalent to the user's guarded declaration in wrapped form:

```text
request-received(
  event="A complete OAK authoring request is received.",
  source=interface.authoring-input,
  guard=ALL($state.ready equals true, $state.approved equals true),
  process=process.author-document,
)
```

S10. Source-less trigger with named seed, equivalent to the user's growth declaration:

```text
growth-requested(event="Continue growing the balance.", process=process.grow-balance, seed=(TARGET=$state.reflection-target))
```

S11. Quoted punctuation and nested JSON values:

```text
message-received(
  event="Received \"go, now\" (draft): x=y; #tag.",
  process=process.inspect,
  seed=(TEXT="a equals b, (c)", DATA={"items": ["x,y", "(z)"]}),
)

IF $state.note equals "a is less than b, (hold)":
  CALL process.review ()
```

S12. Assertion reuse and optional metadata:

```text
ASSERT ALL($state.ready equals true, NOT($state.blocked equals true))
  MESSAGE "Ready and unblocked state is required."
```
