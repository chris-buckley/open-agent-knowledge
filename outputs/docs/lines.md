# Lines

The bound value has a positive line-count bound.

## Examples

```json
[
  {
    "kind": "lines",
    "max": 1
  }
]
```

## Fields

### Kind

`kind`

The constraint discriminator.

```json
[
  "lines"
]
```

### Min

`min`

The fewest lines.

```json
[
  1
]
```

### Max

`max`

The most lines.

```json
[
  1
]
```
