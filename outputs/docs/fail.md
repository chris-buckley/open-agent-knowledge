# Fail

One explicit process failure.

## Examples

```json
[
  {
    "kind": "fail",
    "message": "The result is empty."
  }
]
```

## Fields

### Kind

`kind`

The process step discriminator.

```json
[
  "fail"
]
```

### Message

`message`

The failure message.

```json
[
  "The result is empty."
]
```
