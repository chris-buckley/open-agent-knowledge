# Emission

One validated interface emission.

## Examples

```json
[
  {
    "interface": "stdout",
    "values": {
      "OUTPUT": "/oak"
    }
  }
]
```

## Fields

### Interface

`interface`

The output interface id.

```json
[
  "stdout"
]
```

### Values

`values`

The validated schema bindings.

```json
[
  {
    "OUTPUT": "/oak"
  }
]
```
