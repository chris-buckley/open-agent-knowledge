# StateValue

One value read from a state entry.

## Examples

```json
[
  {
    "source": "state",
    "state": "status"
  }
]
```

## Fields

### Source

`source`

The process value source discriminator.

```json
[
  "state"
]
```

### State

`state`

The state entry to read.

```json
[
  "status"
]
```
