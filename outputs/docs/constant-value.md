# ConstantValue

One value read from a constant entry.

## Examples

```json
[
  {
    "source": "constant",
    "constant": "policy"
  }
]
```

## Fields

### Source

`source`

The process value source discriminator.

```json
[
  "constant"
]
```

### Constant

`constant`

The constant entry to read.

```json
[
  "policy"
]
```
