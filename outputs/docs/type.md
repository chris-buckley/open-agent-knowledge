# Type

The bound value has one datatype from the vocabulary catalog.

## Examples

```json
[
  {
    "kind": "type",
    "of": "string"
  }
]
```

## Fields

### Kind

`kind`

The constraint discriminator.

```json
[
  "type"
]
```

### Of

`of`

The datatype name.

```json
[
  "string",
  "integer",
  "uri"
]
```
