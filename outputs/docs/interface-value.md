# InterfaceValue

One placeholder value read from an active input interface.

## Examples

```json
[
  {
    "source": "interface",
    "interface": "request",
    "placeholder": "REQUEST"
  }
]
```

## Fields

### Source

`source`

The process value source discriminator.

```json
[
  "interface"
]
```

### Interface

`interface`

The active input interface to read.

```json
[
  "request"
]
```

### Placeholder

`placeholder`

The interface schema placeholder to read.

```json
[
  "REQUEST"
]
```
