# DateTime

One aware datetime and its optional IANA time zone name.

## Examples

```json
[
  {
    "value": "2026-08-24T17:35:38+10:00",
    "zone": "Australia/Brisbane"
  }
]
```

## Fields

### Value

`value`

The datetime with a numeric UTC offset.

```json
[
  "2026-08-24T17:35:38+10:00"
]
```

### Zone

`zone`

The optional IANA time zone name.

```json
[
  "Australia/Brisbane"
]
```
