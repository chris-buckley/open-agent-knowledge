# BindingValue

One value read from a prior process-local binding.

## Examples

```json
[
  {
    "source": "binding",
    "binding": "RESULT"
  }
]
```

## Fields

### Source

`source`

The process value source discriminator.

```json
[
  "binding"
]
```

### Binding

`binding`

The visible process-local binding to read.

```json
[
  "RESULT"
]
```
