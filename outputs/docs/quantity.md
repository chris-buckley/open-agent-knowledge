# Quantity

One decimal value and one unit.

## Examples

```json
[
  {
    "value": "10",
    "unit": "kg"
  }
]
```

## Fields

### Value

`value`

The decimal quantity value.

```json
[
  "10",
  "12.5"
]
```

### Unit

`unit`

The unit selected from the shared catalog.

```json
[
  "kg",
  "%"
]
```
