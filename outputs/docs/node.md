# Node

One complete set of the seven parts with nested child nodes.

## Examples

```json
[
  {
    "id": "example-node",
    "instructions": [
      {
        "id": "use-schema",
        "part": "instructions",
        "body": "Use the supplied schema."
      }
    ]
  }
]
```

## Fields

### Id

`id`

The node id, unique across the tree.

```json
[
  "example-node"
]
```

### Instructions

`instructions`
