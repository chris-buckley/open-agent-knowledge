# Call

One synchronous process invocation.

## Examples

```json
[
  {
    "kind": "call",
    "process": "finalize"
  }
]
```

## Fields

### Kind

`kind`

The process step discriminator.

```json
[
  "call"
]
```

### Process

`process`

The process entry to invoke synchronously.

```json
[
  "finalize"
]
```
